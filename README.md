# DecisionNerve landing page

Static landing page for DecisionNerve.

## Files
- index.html
- styles.css
- script.js

## Deployment
No build step. Host on GitHub Pages, Cloudflare Pages, Netlify, Vercel, Namecheap hosting, or any static host.

Keep the Google Workspace MX/SPF/DKIM/DMARC DNS records intact when connecting the domain.
